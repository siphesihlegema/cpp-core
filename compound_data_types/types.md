# Compound data types

Every data type is either a fundamental type or a compound type.
The C++ language standard explicitly defines which category each type falls into.a

C++ supports the following compound types:

*Functions
*C-style Arrays
*Pointer types:
    *Pointer to object
    *Pointer to function
*Pointer to member types:
    *Pointer to data member
    *Pointer to member function
*Reference types:
    *L-value references
    *R-value references
*Enumerated types:
    *Unscoped enumerations
    *Scoped enumerations
*Class types:
    *Structs
    *Classes
    *Unions
